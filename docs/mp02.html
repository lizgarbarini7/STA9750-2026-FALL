Introduction

As Executive Director of the Green Transit Alliance (GTA), each year, I aim to identify the greenest public transit agencies, and award prizes to small, medium, and large transit agencies that have the highest GTA Value Index scores.

The GTA VI estimates the effective emissions reductions by using local ridership data (including total rides and ride distance) and emissions estimates of public transit vehicles (either direct or upstream emissions from electrical generation).

This cata mentioned above is collected via numerous public data sources including:

  • The Energy Information Administration (EIA) State Electricity Profiles, (which informs how carbon intensive electricity is in each state).

  • The National Transit Database (NTD) Energy Consumption report (which includes how much of each fuel every agency and transportation mode used in 2025).

  • The NTD Service by Agency report (which details how many trips and passenger miles each service delivered).

The following report first acquires, cleans ane explores each source. The three data soruces are then joined together, allowing for emissions estimates for every agency and as well as transporation mode to be created. The report then closes with the GTA award winners and a final press release.

Data Acquisition

State Electricity Profiles (Task 1a)

The EIA publishes a summary page for each state. The following code pulls each page once, and combines each returning a “tidy” table. All electricity within a state will be treated as interchangeable, so every electric transit service in a state is assigned that state’s average emissions rate.

Code 
get_eia_sep <- function(state, abbr) {
  library(tidyverse)
  library(stringr)
  library(httr2)
  library(rvest)
  library(fs)

  state_formatted <- str_to_lower(state) |> str_replace_all("\\s", "")

  dir_name <- fs::path("data", "mp02")
  file_name <- fs::path(dir_name, state_formatted)

  fs::dir_create(dir_name, recurse = TRUE)

  if (!fs::file_exists(file_name)) {
    BASE_URL <- "https://www.eia.gov"
    RESPONSE <- request(BASE_URL) |>
      req_url_path(
        "electricity",
        "state",
        state_formatted
      ) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
      ) |>
      req_retry(
        max_tries = 4,
      ) |>
      req_perform(file_name)

    resp_check_status(RESPONSE)
  }

  TABLE <- read_html(file_name) |>
    html_element("table") |>
    html_table() |>
    mutate(Item = str_to_lower(Item))

  if ("U.S. rank" %in% colnames(TABLE)) {
    TABLE <- TABLE |> rename(Rank = `U.S. rank`)
  }

  CO2_MWh <- TABLE |>
    filter(Item == "carbon dioxide (lbs/mwh)") |>
    pull(Value) |>
    str_replace_all(",", "") |>
    as.numeric()

  PRIMARY <- TABLE |>
    filter(Item == "primary energy source") |>
    pull(Rank)

  RATE <- TABLE |>
    filter(Item == "average retail price (cents/kwh)") |>
    pull(Value) |>
    as.numeric()

  GENERATION_MWh <- TABLE |>
    filter(Item == "net generation (megawatthours)") |>
    pull(Value) |>
    str_replace_all(",", "") |>
    as.numeric()

  data.frame(
    CO2_MWh = CO2_MWh,
    primary_source = PRIMARY,
    electricity_price_MWh = RATE * 10, # cents -> dollars, kWh -> MWh
    generation_MWh = GENERATION_MWh,
    state = state,
    abbreviation = abbr
  )
}

EIA_SEP_REPORT <- map2(state.name, state.abb, get_eia_sep) |> list_rbind()

NTD Energy Consumption (Task 1b)

The NTD energy report is an Excel file that lists how much of each fuel every agency used, broken down by modes of transportation. Non-electric fuels are in gallons, and electricity is in kWh. The following code pulls the report and returns it in table form.

load_ntd_energy <- function() {
  library(readxl)
  library(httr2)
  library(tidyverse)
  library(fs)

  # Create 'data/mp02' directory if not already present
  DATA_DIR <- fs::path("data", "mp02")
  fs::dir_create(DATA_DIR, recurse = TRUE)

  NTD_ENERGY_FILE <- fs::path(DATA_DIR, "2025_ntd_energy.xlsx")

  if (!fs::file_exists(NTD_ENERGY_FILE)) {
    library(httr2)

    request("https://www.transit.dot.gov/") |>
      req_url_path(
        "sites",
        "fta.dot.gov",
        "files",
        "2026-09",
        "2025 Energy Consumption_260806.xlsx"
      ) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
      ) |>
      req_perform(NTD_ENERGY_FILE)
  }

  if (file.info(NTD_ENERGY_FILE)$size < 1e4) {
    cat("I was unable to download the NTD Energy File. Please try again.\n")
    stop("Download failed. Please delete the corrupted file by running `unlink('data/mp02/2025_ntd_energy.xlsx')` and try again.")
  }

  to_numeric_fill_0 <- function(x) {
    x <- if_else(x == "-", NA, x)
    replace_na(as.numeric(x), 0)
  }

  read_excel(NTD_ENERGY_FILE) |>
    select(-c(
      `Reporter Type`,
      `Reporting Module`,
      `Gallons of Other Fuel`,
      `Other Fuel Description`
    )) |>
    mutate(across(
      -c(
        `Agency Name`,
        `Mode`,
        `TOS`
      ),
      to_numeric_fill_0
    )) |>
    group_by(`NTD ID`, `Mode`, `Agency Name`) |>
    summarize(across(where(is.numeric), sum),
      .groups = "keep"
    ) |>
    mutate(ENERGY = sum(c_across(c(where(is.numeric))))) |>
    filter(ENERGY > 0) |>
    select(-ENERGY) |>
    ungroup()
}

load_ntd_service <- function() {
  library(httr2)
  library(tidyverse)
  library(fs)

  # Create 'data/mp02' directory if not already present
  DATA_DIR <- fs::path("data", "mp02")
  fs::dir_create(DATA_DIR, recurse = TRUE)

  NTD_SERVICE_FILE <- fs::path(DATA_DIR, "2025_ntd_service.csv")

  if (!fs::file_exists(NTD_SERVICE_FILE)) {
    library(httr2)

    request("https://data.transportation.gov/resource/4fir-qbim.csv") |>
      req_url_query(`$query` = paste(
        "SELECT  `_5_digit_ntd_id` AS `NTD_ID`",
        "`max_agency` AS `AGENCY`",
        "`max_reporter_type` AS `reporter_type`",
        "`max_organization_type` AS `organization_type`",
        "`max_city` AS `city`",
        "`max_state` AS `state`",
        "`mode`",
        "`type_of_service`",
        "`max_primary_uza_code` as `uza_code`",
        "`max_primary_uza_name` as `uza_name`",
        "`max_primary_uza_area_sq_miles` as `uza_sq_miles`",
        "`max_primary_uza_population` as `uza_population`",
        "`max_service_area_sq_miles` as `service_area_sq_miles`",
        "`max_service_area_population` as `service_area_population`",
        "`questionable_record` as `flagged_likely_inaccurate`",
        "`sum_unlinked_passenger_trips_upt` as `total_upt`",
        "`sum_passenger_miles` WHERE caseless_one_of(`report_year`, '2025') limit 50000",
        sep = ","
      )) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
      ) |>
      req_perform(NTD_SERVICE_FILE)

  if (file.info(NTD_SERVICE_FILE)$size < 1e4) {
    cat("I was unable to download the NTD Service File. Please try again.\n")
    stop("Download failed. Please delete the corrupted file by running `unlink('data/mp02/2025_ntd_service.csv')` and try again.")
  }

  read_csv(NTD_SERVICE_FILE) |>
    mutate(flagged_likely_inaccurate = !is.na(flagged_likely_inaccurate))
}

Data Integration

Each question below determines which join is appropriate.

Since every agency needs to appear just once, an agency level table is made, and then an inner_join() is done to connect it to the energy data.

Calculating Total Emissions (Task 5)

Assumptions

To turn fuel use into CO2, each individual fuel is converted into kgs of CO2 (using the published combustion coefficients from the EIA and EPA). For electricity, the kWhs are multiplied by the state’s average grid emissions rate.

Key assumptions made:

  • Only direct emissions are counted for fuels.

  • Compressed natural gas is reported in gallons.

  • The District of Columbia and US territories are not in the EIA table, so their electricity defaults to be the US electricity generation weighted average.

  • All electricity in a state is fungible, even where an agency has a “green power” contract.

Computing emissions

Code 
EMISSIONS <- EMISSIONS_BASE |>
  mutate(
    grid_imputed = is.na(CO2_MWh),
    grid_kg_per_mwh = coalesce(CO2_MWh, us_avg_co2) * LB_TO_KG,
    kwh_total = kwh_battery + kwh_propulsion,
    emissions_kg =
      biodiesel_gal * kg_per$biodiesel +
        bunker_gal * kg_per$bunker +
        cng_gal * kg_per$cng +
        diesel_gal * kg_per$diesel +
        ethanol_gal * kg_per$ethanol +
        gasoline_gal * kg_per$gasoline +
        hydrogen_kg * kg_per$hydrogen +
        kerosene_gal * kg_per$kerosene +
        lng_gal * kg_per$lng +
        lpg_gal * kg_per$lpg +
        kwh_total / 1000 * grid_kg_per_mwh,
    energy_mmbtu =
      biodiesel_gal * mmbtu_per$biodiesel +
        bunker_gal * mmbtu_per$bunker +

# Introduction

As Executive Director of the Green Transit Alliance (GTA), each year, I aim to identify the *greenest* public transit agencies, and award prizes to small, medium, and large transit agencies that have the highest GTA Value Index scores.

The GTA VI estimates the effective emissions reductions by using local ridership data (including total rides and ride distance) and emissions estimates of public transit vehicles (either direct or upstream emissions from electrical generation).


This cata mentioned above is collected via numerous public data sources including:

```{r}
get_eia_sep <- function(state, abbr) {
  library(tidyverse)
  library(stringr)
  library(httr2)
  library(rvest)
  library(fs)

  state_formatted <- str_to_lower(state) |> str_replace_all("\\s", "")

  dir_name <- fs::path("data", "mp02")
  file_name <- fs::path(dir_name, state_formatted)

  fs::dir_create(dir_name, recurse = TRUE)

  if (!fs::file_exists(file_name)) {
    BASE_URL <- "https://www.eia.gov"
    RESPONSE <- request(BASE_URL) |>
      req_url_path(
        "electricity",
        "state",
        state_formatted
      ) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
      ) |>
      req_retry(
        max_tries = 4,
      ) |>
      req_perform(file_name)

    resp_check_status(RESPONSE)
  }

  TABLE <- read_html(file_name) |>
    html_element("table") |>
    html_table() |>
    mutate(Item = str_to_lower(Item))

  if ("U.S. rank" %in% colnames(TABLE)) {
    TABLE <- TABLE |> rename(Rank = `U.S. rank`)
  }

  CO2_MWh <- TABLE |>
    filter(Item == "carbon dioxide (lbs/mwh)") |>
    pull(Value) |>
    str_replace_all(",", "") |>
    as.numeric()

  PRIMARY <- TABLE |>
    filter(Item == "primary energy source") |>
    pull(Rank)

  RATE <- TABLE |>
    filter(Item == "average retail price (cents/kwh)") |>
    pull(Value) |>
    as.numeric()

  GENERATION_MWh <- TABLE |>
    filter(Item == "net generation (megawatthours)") |>
    pull(Value) |>
    str_replace_all(",", "") |>
    as.numeric()

  data.frame(
    CO2_MWh = CO2_MWh,
    primary_source = PRIMARY,
    electricity_price_MWh = RATE * 10, # cents -> dollars, kWh -> MWh
    generation_MWh = GENERATION_MWh,
    state = state,
    abbreviation = abbr
  )
}
```

```{r}
load_ntd_energy <- function() {

  DATA_DIR <- fs::path("data", "mp02")

    library(httr2)

    request("https://www.transit.dot.gov/") |>
      req_url_path(
        "sites",
        "fta.dot.gov",
        "files",
        "2026-09",
        "2025 Energy Consumption_260806.xlsx"
      ) |>
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
      ) |>
      req_perform(NTD_ENERGY_FILE)
  }

  if (file.info(NTD_ENERGY_FILE)$size < 1e4) {
    cat("I was unable to download the NTD Energy File. Please try again.\n")
    stop("Download failed. Please delete the corrupted file by running `unlink('data/mp02/2025_ntd_energy.xlsx')` and try again.")
  }

    x <- if_else(x == "-", NA, x)
    replace_na(as.numeric(x), 0)
  }

  read_excel(NTD_ENERGY_FILE) |>
    select(-c(
      `Reporter Type`,
      `Reporting Module`,
      `Gallons of Other Fuel`,
      `Other Fuel Description`
    )) |>
    mutate(across(
      -c(
        `Agency Name`,
        `Mode`,
        `TOS`
      ),
      to_numeric_fill_0
    )) |>
    group_by(`NTD ID`, `Mode`, `Agency Name`) |>
    summarize(across(where(is.numeric), sum),
      .groups = "keep"
    ) |>
    mutate(ENERGY = sum(c_across(c(where(is.numeric))))) |>
    filter(ENERGY > 0) |>
    select(-ENERGY) |>
```

## Calculating Total Emissions (Task 5)

### Assumptions

To turn fuel use into CO2, each individual fuel is converted into kgs of CO2 (using the published combustion coefficients from the EIA and EPA). For electricity, the kWhs are multiplied by the state's average grid emissions rate.

Key assumptions made:

- Only direct emissions are counted for fuels.

- Compressed natural gas is reported in gallons.

- The District of Columbia and US territories are not in the EIA table, so their electricity defaults to be the US electricity generation weighted average.

- All electricity in a state is fungible, even where an agency has a "green power" contract.

```{r}
#| label: constants

LB_TO_KG <- 0.45359237

# kg of CO2 emitted per gallon of fuel burned (kg for hydrogen: tailpipe = 0)
kg_per <- list(
  biodiesel = 9.45, bunker = 11.27, cng = 6.05, diesel = 10.18,
  ethanol = 5.75, gasoline = 8.89, hydrogen = 0, kerosene = 9.75,
  lng = 4.50, lpg = 5.72
)

# MMBtu of energy contained in one unit of each fuel (kWh for electricity)
mmbtu_per <- list(
  biodiesel = 0.1280, bunker = 0.1496, cng = 0.1140, diesel = 0.1387,
  ethanol = 0.0762, gasoline = 0.1204, hydrogen = 0.1340, kerosene = 0.1350,
  lng = 0.0845, lpg = 0.0913, kwh = 0.003412
)
```

- Agency has fewer than 100,000 annual trips & has unstable ratios.

- Agencies have any record flagged as likely inaccurate.

## About the Analysis

Emissions were estimated from 2025 NTD fuel & electricity data using published EIA and EPA CO2 coefficients and state average grid emissions. # Conclusion

Three findings stand out.

- First, where a transit system operates matters as much as how it operates, because the same electric vehicle produces very different emissions depending on the local grid. 

- Second, the choice of mode dominates the results: electric rail is far cleaner than driving, while low occupancy services can be dirtier.

- Third, the winners of the headline awards are held to the modeling assumptions including the fuel economy of the cars riders would otherwise use. There are limitations, including excluding upstream fuel emissions, assuming every rider would drive alone, and using state-average grid emissions (even if agencies have renewable power contracts).
